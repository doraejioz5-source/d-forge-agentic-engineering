# D-FORGE

Agentic Engineering LLM MVP for structuring early-stage R&D work into requirements, system design, verification, traceability, and development planning.

## Demo scope
Safe, non-operational engineering workflows such as inspection, maintenance, sensing, logistics, reliability, and monitoring.

## Run
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```
